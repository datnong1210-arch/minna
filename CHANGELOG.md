# Changelog

All notable changes to the AhoMINNA plugin will be documented in this file.

## [1.0.0] - 2024-12-11

### Added
- Initial release of AhoMINNA plugin
- Custom post types for lessons, vocabulary, grammar, dialogues, and quizzes
- Flashcard system with flip animations
- Audio player for vocabulary and dialogues
- Video support for dialogues (YouTube embed and direct upload)
- Interactive quiz system with multiple choice questions
- Progress tracking for logged-in users
- Bulk import from CSV for vocabulary and quizzes
- Admin dashboard with statistics
- Fullscreen presentation mode
- Keyboard shortcuts for navigation
- Touch/swipe support for mobile devices
- Responsive design for all screen sizes
- Vietnamese and English language support
- 4 shortcodes for displaying content
- Custom meta boxes for easy content management
- Database tables for progress and quiz results

### Features
- 50 lesson structure for Minna no Nihongo
- Learn and review modes for flashcards
- Grammar patterns with Vietnamese explanations
- Dialogue with speaker identification
- Quiz with instant feedback and explanations
- Landscape mode optimization
- Archive page for all lessons
- Settings page for plugin configuration

### Technical
- WordPress 5.0+ compatibility
- PHP 7.4+ support
- AJAX-powered interactions
- CSS3 animations and transitions
- Accessibility features (WCAG 2.1)
- SEO-friendly structure
- Performance optimized with lazy loading
